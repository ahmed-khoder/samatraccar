## ما هو Tracar؟

واجهة ويب مبنية بـ **Next.js 16 / React 19** تعمل فوق سيرفر Traccar موجود عندك. لا تستبدل Traccar: أجهزتك تستمر
في الإرسال إليه، و Tracar يقرأ كل شيء من واجهته البرمجية (REST API) ويعرضه بواجهة حديثة للتشغيل والإدارة:

| المجال | ماذا تحصل عليه |
|---|---|
| **الخريطة المباشرة** | خرائط مفتوحة المصدر (OpenStreetMap)، المركبات تنزلق بسلاسة بين مواقع GPS، سهم اتجاه، آثار الحركة، أسماء، أسوار جغرافية، ملء الشاشة، أنماط (داكنة/فاتحة/أقمار صناعية/طبوغرافية). |
| **تخصيص المركبات** | 22 نوعًا (سيارة، بيك أب، فان، شاحنة، **شاحنة حاويات بمنظر علوي**، أتوبيس، موتوسيكل، جرار، قارب، طائرة…) وألوان للخريطة، تُحفظ على جهاز Traccar نفسه. |
| **التحليلات** | المسافة، زمن القيادة والوقوف والتوقف، الرحلات والتوقفات، نطاقات السرعة، تجاوز السرعة، الفرملة والتسارع العنيف، تقييم القيادة، استغلال الأسطول. |
| **إعادة تشغيل الرحلة** | مسار ملوّن حسب السرعة، تشغيل/إيقاف/تحكم بالسرعة، خريطة حرارية، رسوم السرعة والارتفاع والبطارية. |
| **مركز التقارير** | نظرة عامة مع ملاحظات تلقائية، ملخص لكل مركبة، تقرير يومي وخريطة حرارية، رحلات، توقفات، سلوك القيادة، أحداث. اختيار عدة مركبات، تواريخ مخصصة (حتى 92 يومًا)، **مقارنة مركبة بمركبة** و**فترة بالفترة السابقة**، تصدير CSV وطباعة/PDF. |
| **التنبيهات والأحداث** | أحداث الإشعال والحركة والأسوار الجغرافية والإنذارات، مع تصفية وترجمة. |
| **تجربة الاستخدام** | عربي/إنجليزي بـ RTL كامل، ثيم داكن/فاتح/حسب النظام، قوائم قابلة للطي والنقل (بداية/نهاية/أعلى/أسفل، مضغوطة عند التمرير أو مفتوحة)، تخطيط للهاتف واللوحي وسطح المكتب. |

> **لماذا نحسب التحليلات بأنفسنا؟** في كثير من تركيبات Traccar تكون قيم `summary` و`trips` المعتمدة على عداد المسافة
> غير موثوقة (عدّاد يُصفَّر فتظهر مسافات سالبة، وأقصى سرعة `0`). Tracar يعيد الحساب من نقاط GPS الخام
> (`/api/reports/route`) فتطابق الأرقام ما فعلته المركبات فعلًا.

## المتطلبات

* سيرفر **Traccar** يعمل (جُرّب مع Traccar 6.0) ويمكن الوصول إليه من مكان تشغيل Tracar.
* حساب مستخدم في Traccar (بريد + كلمة مرور). Tracar **لا يخزّن أي بيانات دخول** — راجع [الأمان](#الأمان).
* **Docker** (موصى به) أو **Node.js ≥ 20.9** للتطوير المحلي.

## التشغيل السريع (Docker)

```bash
git clone https://github.com/elblasy33/samatraccar.git
cd samatraccar
cp .env.example .env
nano .env                      # اضبط TRACCAR_URL=https://عنوان-سيرفر-traccar
docker compose up -d --build   # ← http://<ip-السيرفر>:3000
```

سجّل الدخول بالبريد وكلمة المرور الخاصة بحسابك في Traccar.

> المنفذ 3000 مشغول؟ أضف `APP_PORT=3300` (أي منفذ فاضي) في `.env`.

> يعمل على `http://ip:3000` العادي وخلف HTTPS بنفس الطريقة — علامة `Secure` في كوكي الجلسة تُكتشف تلقائيًا
> (اضبط `COOKIE_SECURE=true|false` فقط لفرضها).

أوامر مفيدة:

```bash
docker compose logs -f tracar     # السجلات
git pull && docker compose up -d --build   # تحديث لآخر نسخة من الكود
docker compose down               # إيقاف (يبقى حجم الكاش)
```

## التشغيل للتطوير

```bash
git clone https://github.com/elblasy33/samatraccar.git
cd samatraccar
cp .env.example .env.local        # اضبط TRACCAR_URL
npm install
npm run dev                       # http://localhost:3000
```

أوامر أخرى: `npm run build` · `npm start` · `npm run lint`.

لفتح سيرفر التطوير من هاتف أو جهاز آخر على نفس الشبكة تصفّح `http://<ip-جهازك>:3000`
(النطاقات الخاصة مسموحة في `next.config.ts`).

## الإعدادات

كل الإعدادات عبر متغيرات البيئة.

| المتغير | مطلوب | الافتراضي | الوصف |
|---|:--:|---|---|
| `TRACCAR_URL` | ✅ | – | عنوان سيرفر Traccar بدون `/` في النهاية. يُقرأ وقت الطلب، فصورة واحدة تصلح لأي سيرفر. |
| `COOKIE_SECURE` | – | تلقائي | يُكتشف لكل طلب (HTTPS أو `X-Forwarded-Proto: https` ⇒ آمن، HTTP عادي ⇒ غير آمن). اضبطه `true`/`false` فقط لفرضه. |
| `CACHE_DIR` | – | `./.cache` (`/data` في Docker) | مكان تخزين كاش التحليلات والعناوين. موصول كـ volume في `docker-compose.yml`. |
| `APP_PORT` | – | `3000` | المنفذ الذي ينشره Docker على السيرفر (`docker-compose.yml`). غيّره إن كان 3000 مشغولًا. |
| `PORT` / `HOSTNAME` | – | `3000` / `0.0.0.0` (Docker) | إعدادات خادم Next.js القياسية. |

تفضيلات المستخدم (الثيم، أماكن القوائم، نمط الخريطة، حد السرعة، تحويل العناوين) تُحفظ في المتصفح وكوكي صغير —
أي لكل جهاز وليس لكل حساب Traccar، وتُغيَّر من صفحة **الإعدادات**.

## النشر خلف Nginx Proxy Manager (دومين + HTTPS)

1. تأكد أن سجل DNS للدومين (مثل `tracar.example.com`) يشير إلى السيرفر الذي يعمل عليه NPM.
2. شغّل Tracar (`docker compose up -d --build`). ثم إمّا:
   * اترك `ports: "3000:3000"` ووجّه إلى `ip-السيرفر:3000`، **أو**
   * ضع Tracar على نفس شبكة Docker الخاصة بـ NPM (فعّل أقسام `networks` في `docker-compose.yml`
     وأزل `ports`) ووجّه إلى اسم الحاوية `tracar` والمنفذ `3000`.
3. في NPM: **Hosts → Proxy Hosts → Add Proxy Host**
   * *Domain Names*: `tracar.example.com`
   * *Scheme*: `http` · *Forward Hostname / IP*: `tracar` (أو IP السيرفر) · *Forward Port*: `3000`
   * فعّل **Block Common Exploits** و **Websockets Support**
4. تبويب **SSL** ← *Request a new SSL certificate* (Let's Encrypt) ← فعّل **Force SSL** و **HTTP/2**.
5. اترك `COOKIE_SECURE` بدون ضبط (NPM يرسل `X-Forwarded-Proto` فيُفعَّل الكوكي الآمن تلقائيًا). افتح `https://tracar.example.com` وسجّل الدخول.

التقارير الطويلة تُجلب على طلبات قصيرة (≤ 7 أيام)، فمهلات الـ proxy الافتراضية كافية.

## البنية

```
المتصفح ──► Next.js (Tracar) ──► Traccar REST API
            │  • الدخول: بريد+كلمة مرور ← جلسة Traccar ← توكن 30 يومًا
            │    يُحفظ في كوكي httpOnly (لا يصل إلى JavaScript أبدًا)
            │  • /api/t/*        وسيط موثّق إلى Traccar (قراءة + تعديل جهاز + أوامر)
            │  • /api/analytics  محرك التحليلات على السيرفر + كاش على القرص
            └  • /api/geocode    تحويل الإحداثيات لعناوين عبر OpenStreetMap Nominatim (اختياري)
```

* **البيانات المباشرة** تُجلب كل 3 ثوانٍ عبر الوسيط، والخريطة تُحاكي الحركة بين المواقع لتبدو متصلة.
* **محرك التحليلات** (`lib/analytics.ts`): يجلب مسار كل مركبة لكل يوم ثم يحسب المسافة (haversine مع تصفية القفزات)،
  زمن القيادة والوقوف والتوقف، الرحلات والتوقفات (توقف ≥ 3 دقائق)، نطاقات السرعة، حالات تجاوز السرعة،
  الفرملة/التسارع العنيف (≥ 8 كم/س في الثانية) وتقييم القيادة. الأيام المنتهية تُخزَّن على القرص
  (`CACHE_DIR/analytics.json`) واليوم الحالي يُعاد حسابه كل ~45 ثانية.
* **تقييم القيادة** = `100 − نسبة تجاوز السرعة × 60 − min(الأحداث العنيفة لكل 100 كم × 3, 40)` ضمن 0–100.
  حد السرعة قابل للتعديل من الإعدادات.
* **التقارير** تقسّم الفترات الطويلة إلى أجزاء 7 أيام تُجلب بالتوازي مع شريط تقدم ثم تُجمَّع في المتصفح.

## الأمان

* **لا بيانات دخول في الكود ولا في الصورة.** كل مستخدم يدخل بحسابه في Traccar؛ يستبدله Tracar بتوكن ويحتفظ بالتوكن فقط
  في كوكي `httpOnly` و`SameSite=Lax` (و`Secure` في الإنتاج).
* الوسيط (`/api/t/*`) يسمح فقط بـ `GET` و`POST commands/send` و`PUT devices/{id}` — لا مستخدمين، لا حذف،
  لا إعدادات سيرفر. كل طلب يُنفَّذ بصلاحيات المستخدم المسجَّل، فصلاحيات Traccar تبقى سارية.
* **إرسال أوامر للأجهزة (مثل قطع المحرك) متاح في الوسيط لكن بلا واجهة** عمدًا.
* **تحويل العناوين عبر OpenStreetMap اختياري** (الإعدادات ← العناوين). عند تفعيله تُرسَل إحداثيات التوقفات إلى خدمة
  Nominatim العامة (مع كاش وبمعدل طلب كل ثانية). الافتراضي هو سؤال سيرفر Traccar.
* بلاطات الخرائط تُحمَّل من OpenStreetMap / Esri / OpenTopoMap، وهذا يكشف المنطقة المعروضة لهذه الجهات.
  راجع سياسات الاستخدام قبل الإنتاج الكثيف، أو بدّل روابط البلاطات في `components/MapView.tsx` بسيرفر خرائط خاص.
* أبقِ ملف `.env` خارج git (هو مُدرج في `.gitignore`).

## قيود معروفة

* التحديث المباشر بالاستعلام الدوري (3 ثوانٍ) وليس عبر WebSocket.
* التحليلات تُحسب لأيام كاملة؛ الرحلة التي تعبر منتصف الليل تنقسم بين اليومين.
* الأجهزة ذات الساعة الخاطئة (مثل فرق ثابت +8 ساعات أو تاريخ GPS من 2007) تُكتشف وتُعلَّم
  ("بدون إشارة GPS" / تنبيه انحراف الساعة) لكن لا تُصحَّح؛ الأوقات المعروضة هي أوقات الجهاز.
* لا تقارير مجدولة أو بالبريد، ولا تقارير الصيانة والوقود بعد.
* التفضيلات مخزّنة لكل متصفح وليس في حساب Traccar.

## حل المشاكل

| العَرَض | الحل |
|---|---|
| الدخول ينجح ثم تعود لصفحة الدخول | المتصفح أسقط كوكي الجلسة. حدّث لآخر نسخة (تكتشف HTTP/HTTPS تلقائيًا)؛ وإن كنت فرضت `COOKIE_SECURE=true` مع HTTP عادي فاحذفها. |
| `TRACCAR_URL is not set` | أنشئ `.env` (Docker) أو `.env.local` (تطوير) من `.env.example`. |
| التقارير فارغة لتواريخ قديمة | Traccar لا يملك بيانات قبل بدء الأجهزة بالإرسال. |
| "تعذّر تحميل بعض الأيام" | السيرفر قطع اتصالًا؛ أعد التحميل — الأيام المنتهية مخزّنة فيُعاد جلب الناقص فقط. |
| أول تحميل لتقرير 30–90 يومًا بطيء | أول مرة يُحسب كل يوم من GPS الخام، وبعدها يُقدَّم من الكاش. |
| سيرفر التطوير يعرض "Blocked cross-origin request" | أضف المضيف إلى `allowedDevOrigins` في `next.config.ts` وأعد تشغيل `npm run dev`. |
